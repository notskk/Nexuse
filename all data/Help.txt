Create Animation:
One-click pipeline that does everything automatically:
  1. Extracts frames from your video
  2. Uploads all frames to Roblox
  3. Waits for CDN processing then resolves texture IDs
  4. Builds the animation timeline and encodes it
  5. Copies the encoded string to your clipboard
Set your video, Run ID, and FPS — then click Create Animation.
Each step has its own progress bar so you can see exactly where it is.

Profiles:
Manage multiple Roblox API credentials.
When creating a new profile, you'll see a safety warning.
Set an active profile before using Create Animation.

Extraction Settings:
Modes: All Frames, By FPS, By Interval (ms).
Formats: PNG or JPEG (with quality slider).
Extract to Folder or Extract to ZIP.

Encoder / Decoder:
Encode JSON → Base64+zstd for Roblox.
Decode Base64+zstd → readable JSON.

Features:
Dashboard — Overview and quick actions.
Animation Uploader — Video extraction and animation pipeline.
Encoder / Decoder — Compress and decompress data.
Profiles — Multiple credential management.
Statistics — Run history and frame counts.
Settings — Themes and display options.
Logs — View all subprocess output.
